## 安装与运行

### 环境要求

- Python 3.10+
- Windows / macOS / Linux

### 安装步骤

```bash
# 1. 进入 docs 目录
cd Calendar-Mod/docs

# 2. 安装依赖
pip install -r requirements.txt

# 或单独安装核心依赖
pip install PySide6>=6.6.0
```

### 运行

```bash
python resource_pack_generator.py
```

首次启动会显示主窗口。

## 快速上手

只需 4 步即可生成资源包：

### 第 1 步：新增样式

点击 **➕ 新增**，在弹出的对话框中填写：

- **样式 ID**：英文小写+下划线（如 `neon_style`）
- **显示名称**：在配置界面下拉框中显示的名字
- **CSS 文件**：相对路径（如 `styles/neon.css`）

### 第 2 步：配置 HUD 颜色

在新增对话框底部的 **HUD 颜色配置** 区域：

- 点击任意颜色按钮打开系统颜色选择器
- 选择颜色后自动更新预览
- 可点击底部预设按钮一键套用内置样式配色

### 第 3 步：编写 CSS

切换到 **🎨 CSS 模板** 标签：

- 直接在编辑器中编写 CSS
- 或点击 **套用模板** 选择内置模板作为起点
- 修改 `styles/` 下的 CSS 文件路径

### 第 4 步：导出

点击工具栏 **📦 导出资源包**：

1. 选择导出目录
2. 输入资源包文件夹名（如 `my_calendar_style`）
3. 导出完成后将文件夹放入 `.minecraft/resourcepacks/`
4. 游戏内启用资源包即可

## 功能详解

### 样式列表操作

| 按钮 | 功能 |
|------|------|
| ➕ 新增 | 弹出对话框创建新样式 |
| ✏️ 编辑 | 修改选中样式的所有字段 |
| 📋 复制 | 复制选中样式为新条目（自动生成不重复 ID） |
| 🗑️ 删除 | 移除选中的样式（内置样式删除后变为自定义覆盖） |

### 对话框功能

#### 基本信息

- **样式 ID**：必填，英文小写字母开头，仅含小写字母/数字/下划线
- **显示名称**：可选，默认与 ID 相同
- **描述**：可选，仅用于记录
- **CSS 文件**：必填，相对 `templates/` 的路径
- **内置**：资源包样式通常设为否

#### HUD 颜色配置

- 7 种颜色可独立配置
- 支持 alpha 透明度通道
- 可点击预设按钮快速套用
- 实时预览 HUD 外观

#### HUD 预览

- 对话框底部实时显示 HUD 渲染效果
- 包括背景、装饰条、主/次要/事件文字颜色
- 所有修改立即反映

### 资源包设置

| 字段 | 说明 | 推荐值 |
|------|------|--------|
| pack_format | Minecraft 资源包格式版本 | 15（1.20.1） |
| description | 资源包描述文本 | 自定义 |

## 字段说明

### styles.json 字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | String | 是 | 样式唯一标识符 |
| `name` | String | 否 | 显示名称 |
| `description` | String | 否 | 样式描述 |
| `file` | String | 是 | CSS 文件路径 |
| `builtin` | Boolean | 否 | 是否内置（默认 true） |
| `hud` | Object | 否 | HUD 颜色配置（见下表） |

### HUD 颜色字段

| 字段 | 用途 | 渲染位置 |
|------|------|----------|
| `shadow` | 阴影颜色 | HUD 外围多层外扩 |
| `body` | 主体背景 | HUD 主背景矩形 |
| `decor` | 装饰条 | 顶部 3px 装饰带 |
| `border` | 边框颜色 | 1px 圆角边框 |
| `textPrimary` | 主文字 | 第 1 行 |
| `textSecondary` | 次要文字 | 第 2 行及以后 |
| `textEvent` | 事件文字 | ◆ 开头的行 |

### 颜色格式

支持以下格式：

| 格式 | 示例 | 说明 |
|------|------|------|
| `#RRGGBB` | `#FF5733` | 6 位，不透明 |
| `#RRGGBBAA` | `#FF573380` | 8 位，AA=透明度 |
| `#RGB` | `#F53` | 3 位缩写 |
| `#RGBA` | `#F538` | 4 位缩写 |

> **alpha 在末尾**：00=完全透明，FF=完全不透明

## 导出资源包

### 方式一：文件夹导出

点击 **📦 导出资源包** → 选择目录 → 输入名称

生成结构：

```
my_calendar_style/
├── pack.mcmeta
└── assets/
    └── calendarmod/
        └── templates/
            ├── styles.json
            └── styles/
                └── my_style.css
```

### 方式二：ZIP 导出

点击 **🗜️ 导出 ZIP** → 选择保存位置

直接生成 `.zip` 文件，解压后放入 `resourcepacks/` 即可。

### 启用资源包

1. 将文件夹或解压的 ZIP 放入 `.minecraft/resourcepacks/`
2. 启动 Minecraft
3. 进入 **选项 → 资源包**
4. 启用你的资源包
5. 进入游戏，打开日历 → 客户端设置 → 选择你的样式

## 常见问题

### Q: 启动时报 "缺少 PySide6 依赖"？

运行：`pip install PySide6>=6.6.0`

### Q: 样式 ID 可以用中文吗？

不可以。ID 必须为英文小写字母开头，仅含小写字母、数字和下划线。这是因为 ID 用于 JSON 键名和样式匹配。

### Q: 导出后游戏内看不到新样式？

检查：
1. `styles.json` 中 `id` 是否唯一
2. `file` 路径是否正确指向你的 CSS 文件
3. 资源包是否已启用（不是"可用"状态）
4. 是否在日历 → 客户端设置 中选择了该样式

### Q: 如何覆盖内置样式？

在 styles.json 中使用与内置样式相同的 `id`（如 `dark`），高优先级资源包会覆盖低优先级。

### Q: HUD 颜色不写会怎样？

不写 `hud` 字段时，HUD 使用默认灰白配色，不会影响日历主界面。

### Q: 多个资源包的样式如何合并？

所有资源包的 styles.json 都会被合并。同 id 样式高优先级覆盖低优先级，不同 id 全部保留。

### Q: 导出的 pack_format 该填多少？

| Minecraft 版本 | pack_format |
|----------------|-------------|
| 1.20.1 | 15 |
| 1.20 - 1.20.4 | 15 |
| 1.19.x | 9 |
| 1.18.x | 8 |

### Q: 工具支持哪些操作系统？

Windows / macOS / Linux 均可运行，只需安装 Python 3.10+ 和 PySide6。
